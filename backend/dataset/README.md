# AcadTrack synthetic dataset - NO-ATTENDANCE VARIANT

All data is FICTIONAL (generated by generate_dataset.py, seed 2025). Emails use example.com.
Same students, courses, semesters and grades as the full dataset; attendance is removed.

## Rules used
- 5-point scale: 70-100 A(5), 60-69 B(4), 50-59 C(3), 45-49 D(2), 40-44 E(1), 0-39 F(0). Pass mark 40.
- Semester GPA = sum(grade_point x credit_units) / sum(credit_units).
- Probation: GPA < 1.5 OR more than 2 failed courses. (No attendance rule.)

## Profile
- 37 of 349 student-semesters flagged (about 11%).
- No AttendanceRecord table needed; remove it from the schema and the attendance
  parts of the dashboards, probation rules and report text.
